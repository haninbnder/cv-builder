# CV Builder

A web-based CV Builder developed as a graduation
project for creating and managing professional
and school resumes.

## Features

- User registration and login
- Professional resume creation
- School resume creation
- User dashboard
- Resume management
- Resume preview and printing
- MySQL database integration

## Technologies Used

- HTML5
- CSS3
- JavaScript
- PHP
- MySQL
- XAMPP

## Project Structure

- assets/ - CSS and design files
- config/ - Database configuration
- includes/ - Shared header and footer
- index.php - Home page
- login.php - User login
- register.php - User registration
- dashboard.php - User dashboard
- create_resume.php - Professional resume creation
- create_school_resume.php - School resume creation
- preview.php - Resume preview
- print_resume.php - Resume printing
